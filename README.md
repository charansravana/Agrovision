# AgroVision – Plant Disease Detection System

AgroVision is a **deep learning–based plant disease detection system** designed to help farmers and researchers identify plant diseases quickly and accurately using leaf images.

The project uses a **modern frontend stack (React + Vite + Tailwind CSS)** and a **deep learning model based on MobileNetV2** to classify plant diseases.

---

## 🚀 Features

* 🌿 Predicts **9 different types of plant diseases**
* ⚡ Fast and lightweight deep learning model (MobileNetV2)
* 🖼️ Image-based disease detection
* 💻 Clean and responsive UI built with Tailwind CSS
* 🔗 Frontend–Backend separated architecture

---

## 🛠️ Tech Stack

### Frontend

* **React** (with Vite for fast development)

### Backend / ML

* **Node.js** (server-side API)
* **Python** (model training)
* **TensorFlow / Keras**
* **MobileNetV2** (Transfer Learning)
* **Python**
* **TensorFlow / Keras**
* **MobileNetV2** (Transfer Learning)

---

## 🧠 Deep Learning Model

* Pretrained **MobileNetV2** used as a feature extractor
* Fine-tuned on a custom plant disease dataset
* Optimized for accuracy and inference speed
* Capable of classifying **9 plant disease categories**
